# Logger by SQ3TOM — Android 0.1

Natywny projekt Android przygotowany jako odejście od testowego HTML.

## Obecnie
- ekran terenowy obsługiwany natywnymi kontrolkami Androida;
- UTC proponowany automatycznie;
- pasma i tryby: AM, SSB, DMR, FM, C4FM, FT8, FT4, JS8, CW;
- zapamiętywanie pasma, trybu, częstotliwości i mocy;
- RST nadany/odebrany;
- moc w W;
- GPS + Maidenhead locator;
- tryb SAT/SPLIT, m.in. ISS, SO-50, AO-91, AO-92, PO-101, RS-44;
- aktywacje: POTA, SOTA, LLOTA, WWFF;
- lokalna historia QSO.

## Następny etap
- prawdziwe QRZ Callbook API i Logbook API;
- pełny ADIF;
- prawdziwa edycja QSO;
- bezpieczne przechowywanie klucza QRZ;
- eksport/backup;
- dopracowanie UI pod jedną rękę.

Środowisko użyte do przygotowania projektu nie posiada Android SDK/Gradle, dlatego ten etap dostarcza projekt źródłowy do otwarcia w Android Studio, a nie udawany APK.
